오늘서재지도 책 찾기

지도 규칙

빛 알갱이 1개 = 읽은 10쪽(book_logs 합계). 분야 = 구형 성단(피보나치 구면 분포, 75%는 껍질 쪽, 25%는 내부), 천천히 자전, 깊이에 따라 크기·밝기 변화, 가산 혼합(lighter) 발광.

책 = 성단 안 큰 별. 흰 테두리 = 다 읽음, 깜빡이는 고리 = 읽는 중, 테두리만 = 읽을 책.

가운데 핵 = 내 서재(✦). 핵 → 분야 허브 곡선, book_links = 책 사이 선.

배경: 별 380개(대각선 은하수 띠 55%), 성운 빛 3개, 시차(parallax) 이동.

탭: 성단 → 확대 + 분야 시트 / 책 → 연결 선 강조 + 책 시트 / 빈 곳 → 전체.
