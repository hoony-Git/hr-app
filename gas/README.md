# hr-app 기기 간 동기화 설치 가이드 (Apps Script)

폰과 PC가 같은 기록을 보게 하는 **저장 창구**를 내 구글 계정에 만드는 과정입니다.
앱 화면은 지금처럼 GitHub Pages 에서 열리고, 이 창구는 기록만 맡아 둡니다. 약 10분 걸립니다.

## 1. 프로젝트 만들기
1. 브라우저에서 <https://script.google.com> 접속 (앱에 쓸 구글 계정으로 로그인)
2. 왼쪽 위 **새 프로젝트** 클릭
3. 왼쪽 위 제목 "제목 없는 프로젝트"를 `hr-app-sync` 로 바꾸기

## 2. 코드 붙여넣기
1. 편집기에 원래 들어 있는 `function myFunction() {}` 를 **전부 지우기**
2. 이 폴더의 `Code.gs` 내용을 **전부 복사해서 붙여넣기**
3. 저장 (Ctrl+S)

## 3. 비밀키 정하기
비밀키는 "이 창구에 접근해도 되는 사람"을 가르는 암호입니다. 주소를 아는 것만으로는 기록을 볼 수 없게 막아 줍니다.

1. 32자 이상의 아무 문자열을 만듭니다. 예: 비밀번호 관리자의 "랜덤 비밀번호 생성" 사용
   (PC 터미널이라면 `openssl rand -hex 24` 로 48자를 만들 수 있습니다)
2. Apps Script 왼쪽 메뉴의 **프로젝트 설정(톱니바퀴)** 클릭
3. 아래쪽 **스크립트 속성** → **스크립트 속성 추가**
   - 속성: `SYNC_TOKEN`
   - 값: 방금 만든 문자열
4. **스크립트 속성 저장**
5. 이 문자열은 따로 안전한 곳에 적어 두세요. 폰과 PC 앱에 똑같이 입력해야 합니다.

> 이 문자열을 GitHub 나 카톡 단체방 등에 올리지 마세요. 저장소가 공개라서 올리면 누구나 볼 수 있습니다.

## 4. 웹앱으로 배포
1. 오른쪽 위 **배포** → **새 배포**
2. 톱니바퀴(유형 선택) → **웹 앱**
3. 설정
   - 설명: `v1`
   - 다음 사용자로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
   - ("모든 사용자"여도 비밀키가 없으면 기록이 나가지 않습니다)
4. **배포** 클릭 → 권한 승인 창이 뜨면 **액세스 승인** → 내 계정 선택
   - "Google에서 확인하지 않은 앱" 경고가 뜨면 **고급** → **hr-app-sync(안전하지 않음)로 이동** → **허용**
   - 내 드라이브에 파일을 만들기 때문에 나오는 정상 절차입니다
5. 나온 **웹 앱 URL** (`https://script.google.com/macros/s/.../exec`)을 복사

## 5. 앱에 입력 (폰, PC 각각)
1. 앱 → **내정보** → **🔄 동기화**
2. **동기화 주소**에 위 `/exec` URL, **비밀키**에 3번 문자열 입력
3. **저장** → **연결 테스트** 로 "연결 정상" 확인 → **지금 동기화**
4. 처음 연결하는 기기는 서버가 비어 있으면 이 기기 기록이 올라가고, 서버에 기록이 있으면 선택 창이 뜹니다.

## 책 ISBN 자동 조회 켜기 (국립중앙도서관 서지정보)
같은 창구가 ISBN 으로 책 제목·저자·출판사·쪽수를 찾아 줍니다. 동기화 주소·비밀키가 설정된 기기에서 책 추가 화면에 ISBN 13자리를 넣으면 비어 있는 칸이 채워집니다.
**먼저 위 1~5번(동기화 설정)이 끝나 있어야 합니다.** 특히 3번의 `SYNC_TOKEN` 스크립트 속성이 없으면 서버가 앱의 모든 요청을 거절해서 조회가 안 됩니다 (앱에는 "동기화가 꺼져 있어…" / "비밀키가 서버와 달라요" 같은 이유가 표시됩니다). 스크립트 속성에 `SYNC_TOKEN` 과 `NL_CERT_KEY` 두 줄이 모두 있어야 합니다.
**인증키는 앱·저장소·채팅에 넣지 말고 아래 스크립트 속성에만** 넣으세요. (이 창구는 비밀키가 맞아야만 조회해 줍니다.)

1. 이 폴더의 `Code.gs` 를 다시 **전부 복사해서 붙여넣기** (기존 내용을 덮어쓰기) → 저장
2. **프로젝트 설정(톱니바퀴)** → **스크립트 속성** → 속성 추가
   - 속성: `NL_CERT_KEY`
   - 값: 국립중앙도서관에서 발급받은 인증키
3. 편집기 위쪽 함수 선택에서 **`authorizeNl`** 을 고르고 **▶ 실행** (처음 한 번만)
   - **`testIsbn` 이 아니라 `authorizeNl` 입니다.** `testIsbn` 은 오류를 잡아서 결과로 돌려주기 때문에 권한이 없어도 승인 창이 뜨지 않고 `upstream_error`(권한 없음) 만 나옵니다.
   - "승인 필요" 창이 뜨면 **권한 검토**를 누릅니다. 새 창이 안 열리면 아래 실행 기록의 **"여기를 클릭하여 권한 제공"** 링크를 누르세요.
   - "Google에서 확인하지 않은 앱" → **고급** → **hr-app-sync(으)로 이동(안전하지 않음)** → 요청 권한이 "외부 서비스에 연결" 하나인지 확인하고 **계속**. (개발자가 본인 계정이어야 정상)
   - 승인되면 창이 저절로 닫힙니다. 편집기가 멈춰 보이면 **새로고침**하세요.
4. 함수 선택에서 **`testIsbn`** 을 고르고 **▶ 실행** → 아래 **실행 로그**에 `{"ok":true,"book":{...}}` 가 나오면 성공입니다. 인증키는 로그에 나오지 않습니다.
   - `not_found` 나 빈 제목이면 `testIsbnRaw` 를 실행해 나온 응답(인증키는 `***` 로 가려짐)을 확인하세요. 응답 항목 이름이 다르면 `mapDoc_` 만 고치면 됩니다.
5. **재배포**: 아래 "코드를 고친 뒤 다시 배포하는 법"대로 **새 버전**으로 배포 (URL 은 그대로)
   - 권한이 늘어났기 때문에 배포 중 승인 창이 한 번 더 뜰 수 있습니다.

| 응답 `error` | 뜻 |
|---|---|
| `unauthorized` | 비밀키가 다름 |
| `not_configured` | `NL_CERT_KEY` 스크립트 속성이 없음 |
| `bad_isbn` | ISBN 형식이 아님 (978/979 로 시작하는 13자리) |
| `upstream_error` | 국립중앙도서관 쪽 오류 (`code` 010 = 인증키 문제) |
| `not_found` | 그 ISBN 의 책 정보가 없음 → 앱은 Google Books 로 한 번 더 찾고, 그래도 없으면 직접 입력 |

점검: `node gas/test_isbn.js` (실제 서버에 접속하지 않고 코드 동작만 확인)

## 코드를 고친 뒤 다시 배포하는 법
코드를 수정하면 **저장만 해서는 반영되지 않습니다.**
1. **배포** → **배포 관리**
2. 연필(수정) 아이콘 → 버전: **새 버전** → **배포**
3. URL 은 그대로 유지됩니다 (앱 설정을 다시 입력할 필요 없음).
- "새 배포"를 누르면 URL 이 바뀌므로 피하세요.

## 어디에 저장되나
- 내 드라이브 맨 위: `hr-app-sync.json` (현재 기록)
- 내 드라이브 `hr-app-backups` 폴더: 저장할 때마다 직전 상태 사본. 최신 30개만 남기고 오래된 건 휴지통으로 갑니다.
- 문제가 생기면 사본 하나를 `hr-app-sync.json` 내용에 덮어써서 되돌릴 수 있습니다.

## 문제 해결
| 증상 | 확인할 것 |
|---|---|
| 인증 실패 | 비밀키가 폰/PC/스크립트 속성에서 완전히 같은지 (공백 포함 주의) |
| 오프라인 | 인터넷 연결, URL 이 `/exec` 로 끝나는지 (`/dev` 는 안 됨) |
| 코드 고쳤는데 그대로 | "새 버전"으로 재배포했는지 |
| 충돌 | 다른 기기에서 먼저 바꾼 기록이 있음. 앱의 선택 창에서 고르면 됨 (양쪽 사본은 자동 보관) |
